# Dryland Log

수영을 위한 웨이트(드라이랜드) 트레이닝 기록 앱입니다. 안드로이드 크롬에서 **앱으로 설치**해서 씁니다.

## 1. 인터넷에 올리기 (GitHub Pages, 무료)

앱을 폰에 설치하려면 파일이 `https://` 주소에 올라가 있어야 합니다. 처음 한 번만 하면 됩니다.

1. <https://github.com> 에서 계정을 만들고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**
   - Repository name: `dryland-log`
   - **Public** 선택 → **Create repository**
3. 만들어진 화면에서 **uploading an existing file** 링크를 누릅니다.
4. zip을 풀면 나오는 **파일 16개를 전부 선택**(Ctrl+A)해서 끌어다 놓습니다.
   - 폴더 없이 파일만 있습니다. 전부 한 곳에 올리면 됩니다.
5. 아래 **Commit changes** 를 누릅니다.
6. 저장소의 **Settings** → 왼쪽 **Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
7. 1~2분 뒤 같은 화면에 주소가 뜹니다. 예: `https://내아이디.github.io/dryland-log/`

> 저장소를 Public으로 만들면 **앱 코드와 엑셀에서 옮긴 기본 기록(seed.js)** 은 누구나 볼 수 있습니다.
> 실제로 앱에서 새로 입력하는 기록은 폰에만 저장되고 인터넷에 올라가지 않습니다.
> 기본 기록도 공개하고 싶지 않다면 올리기 전에 말씀해 주세요. seed.js에서 기록을 빼고 종목 목록만 남겨드리겠습니다.

## 2. 안드로이드 폰에 설치

1. 폰의 **크롬**에서 위 주소를 엽니다.
2. 오른쪽 위 **⋮** → **앱 설치** (또는 **홈 화면에 추가**)
3. 홈 화면의 **Dryland** 아이콘으로 실행합니다. 주소창 없이 전체 화면으로 열립니다.

한 번 열고 나면 **인터넷이 없어도** 작동합니다 (헬스장 지하 등).

## 3. 사용법 요약

| 하고 싶은 것 | 방법 |
|---|---|
| 운동 시작 | 운동 탭 → **운동 시작** / **지난 운동 반복** / 루틴 누르기 |
| 종목 추가 | **+ 종목 추가** → 여러 개 선택 → **추가** (지난번 무게·세트가 자동으로 채워짐) |
| 컨트라스트 세트 (트랩바 데드 + CMJ) | 종목 추가에서 두 개 선택 → **슈퍼세트로 추가**, 또는 종목 메뉴(⋯) → **아래 종목과 슈퍼세트로 묶기** |
| 무게·횟수 입력 | 칸을 누르면 키패드가 열림. 지난 기록 칩을 누르면 한 번에 채워짐 |
| 세트 완료 | 키패드의 **세트 완료** 또는 오른쪽 체크. 다음 칸으로 자동 이동하고 휴식 타이머가 시작됨 |
| 워밍업 표시 | 세트 번호를 누름 → **워밍업 세트로 표시** (볼륨·PR 계산에서 제외) |
| 트랩바·레그프레스 | 기록 방식이 **원판만** — 원판 합계(kg)를 입력하면 `한쪽 2장`처럼 표시. **±1장** 버튼은 양쪽 20kg씩(40kg) |
| 중량 풀업·친업 | 기록 방식이 **맨몸 + 추가 중량** — 추가한 무게만 입력 (더보기에서 몸무게를 넣으면 추정 1RM 계산에 반영) |
| 지난 기록 수정 | 기록 탭 → 날짜 → 기록 → **수정** |
| 성장 확인 | 분석 탭 → 종목 선택 → 추정 1RM / 최고 무게 / 볼륨 그래프 |
| 기록 삭제 · 복원 | 지운 기록은 **휴지통**에 30일 보관 후 자동 삭제. 지운 직후 나오는 **되돌리기**, 또는 더보기 → 휴지통 → **복원** |
| 폰 뒤로가기 | 키패드·창 닫기 → 이전 탭으로 이동 → 첫 화면에서는 한 번 더 누르면 앱이 닫힘 |

### 휴식 알림에 대해
- 앱 화면이 켜져 있으면 휴식이 끝날 때 **소리 + 진동 + 빨간 표시**로 알려줍니다. 운동 중에는 화면이 꺼지지 않게 해둡니다.
- 다른 앱으로 넘어가면 **더보기 → 앱 밖에 있을 때 알림**을 켜야 알림이 옵니다. 다만 화면을 완전히 끄면 늦게 오거나 안 올 수 있습니다 (웹앱의 한계).

### 백업
기록은 **이 폰에만** 저장됩니다. 2주에 한 번은 **더보기 → 백업 파일 저장**을 눌러 주세요.
폰을 바꾸면 새 폰에서 **백업 파일 불러오기**로 옮깁니다.

## 4. 앱을 수정해서 다시 올릴 때
1. 코드를 고쳤다면 `sw.js`의 `VERSION`과 `store.js`의 `APP_VERSION`을 함께 올립니다 (예: `dryland-v3`/`v3` → `dryland-v4`/`v4`).
   - 이 값은 앱 내부의 버전 이름이고, 앱 주소와는 관계없습니다.
2. GitHub 저장소 첫 화면에서 **Add file → Upload files** → 파일 16개를 전부 선택해 끌어다 놓기 → 아래 **Commit changes**.
   - 같은 이름의 파일은 새 파일로 덮어써집니다.
3. **10분쯤** 기다린 뒤 폰에서 앱을 엽니다 (GitHub가 파일을 약 10분간 캐시합니다).
   - 새 버전이 준비되면 앱이 한 번 저절로 새로고침됩니다. 운동 중이면 **지금 적용** 버튼이 뜹니다.
4. **더보기** 맨 아래 **앱 버전**으로 적용됐는지 확인합니다. 기록은 그대로 유지됩니다.

## 5. 엑셀 일지를 옮기면서 해석한 부분
확인이 필요한 부분이 있으면 앱에서 **기록 → 수정**으로 고칠 수 있습니다.

- 연도는 모두 **2026년**으로 넣었습니다.
- `100kg 5x3` → **5회 × 3세트**로 해석 (다른 기록의 `무게 x 횟수 세트` 순서를 따름)
- 트랩바 데드 `원판 130kg`, `20kg 2장` → 원판만 합계 (2장 = 한쪽 20kg×2 = **80kg**, 3장반 = **140kg**)
- `서전트` → **Countermovement Jump (CMJ)**, `암풀다운` → **Straight-Arm Pulldown**
- `중량 풀업 - 친업으로 함`, `언더그립 풀업` → **Weighted Chin-up** / `오버그립 풀업` → **Weighted Pull-up**
- `40kg 4.5` → 4.5회로 그대로 기록
- 4/14 `구산역 30' 6,6,4`, 충무·DMC 기록은 **수영 기록**으로 분류
- `6/28 수원 대회`, `5/2 5/3 kbs 스타트` → **대회 일정**으로 등록
- 4/30 `목표 : 데드 145, 친업 45 3 x 3` → **목표** 두 개로 등록
- 무게·횟수 없이 이름만 있는 종목은 메모 “적당히 수행”으로 남김
- 7/15 `하이로우`는 그립이 적혀 있지 않아 **High Row (Overhand)** 로 넣었습니다
